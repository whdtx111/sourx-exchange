# SourX Exchange 第一版实现进度

更新时间：2026-10-31
分支：`feature/v1.0.0`

## 角色交易平台

- 买家：概览、市场/详情、订单/详情、任务空间、账单、账户安全。
- 卖家：经营概览、设备节点、商品管理、租出订单/详情、收益结算、账户安全。
- 运营：审核商品、订单结算、操作审计。
- 真实登录与服务端角色/资源所有权校验；关闭本地开发身份绕过，移除旧全角色 Demo 概览和静态页面。
- 买家筛选/下单/测试支付/任务/结束/结算闭环，卖家编辑商品后重新审核，历史订单价格保持快照。
- 单实例原子文件持久化和 Docker 命名卷，恢复账号、会话、交易、任务、计量、账本与 Agent 凭证。
- Chrome 端到端测试覆盖双角色页面和交易流程，包含手机布局与截图。
- 详见[角色交易平台验收](角色交易平台验收.md)和[本地部署](本地Demo部署.md)。

## 已完成并自测

- TypeScript + Fastify + Vitest 工程基线。
- buyer/provider/operator 角色、开发 bootstrap、邮箱注册、scrypt 密码哈希、HMAC access token、refresh 轮换、登出和账户停用。
- 节点登记、一次性 enrollment code、Agent 凭证、心跳、签名命令拉取和 ack。
- Listing 审核发布、整数最小货币单位报价、GPU 独占和 15 分钟下单预留；预留过期或支付失败会释放。
- 订单、支付授权、租约、订单结束清理编排；清理顺序为取消 Job -> 撤销 token -> 停止/销毁 sandbox -> 删除 artifact -> 释放 GPU。
- capability token 的订单/租约/scope/TTL/版本校验，订单结束后旧 token 失效。
- 默认 Job API、镜像 digest 白名单、输入 artifact 订单前缀隔离、上传完成、读取和下载 URL。
- sandbox 规格拒绝 root、特权、宿主挂载、host namespace、可写根文件系统、未丢弃 capabilities、无资源上限和内网/metadata 出口。
- 固定计量时间桶、真实 GPU UUID 校验、重复事件幂等、支付 webhook HMAC 验签和 eventId 幂等。
- 结算账本、平台费、卖家应收、争议冻结和退款幂等。

## 主要 HTTP 入口

- `/v1/auth/*`：注册、登录、refresh、登出。
- `/v1/agent/enrollment-codes`、`/v1/agent/enroll`、`/v1/agent/nodes/:id/heartbeat`：节点接入。
- `/v1/agent/nodes/:id/commands`：Agent 拉取签名命令；`.../ack` 回传结果。
- `/v1/gateway/jobs`、`/v1/gateway/artifacts`：受限任务和订单输入数据。
- `/v1/agent/leases/:id/meter`：Agent 计量上报。
- `/v1/orders/:id/end|metering|dispute|settle|refund`：订单生命周期和结算。
- `/v1/payments/webhooks/:provider`：支付 webhook。

## 当前边界

当前实现是可运行的单实例控制面（内存模型与文件持久化）及角色工作台，尚未接入：

- PostgreSQL、Redis、S3/对象存储。当前仅实现单实例本地文件持久化。
- Linux Go Agent、Docker/NVIDIA Container Toolkit、真实反向隧道和 mTLS。
- 真实支付渠道的预授权、分账、退款和每日对账。
- 生产身份服务、KYC、限流和独立审计服务。当前已提供基础运营后台，审计事件随本地状态持久化。

`/v1/users` 仅在 `NODE_ENV=test` 或显式设置 `ALLOW_DEV_AUTH_BYPASS=true` 时可用。生产部署必须关闭该入口、配置独立的 `AUTH_SECRET`、`CAPABILITY_SECRET`、`AGENT_COMMAND_SECRET` 和 `PAYMENT_WEBHOOK_SECRET`，并把内存服务替换为持久化实现。
