# SourX Exchange

算力交易平台，目标是让个人 PC、GPU 服务器和机构节点以可计量、可审计的租约方式提供算力。

当前仓库处于从零设计阶段。开发前请先阅读：

- [算力交易平台开发方案](docs/算力交易平台开发方案.md)
- [第一版详细开发计划](docs/第一版详细开发计划.md)

前一份文档定义首期推荐架构、三种开发路线、核心状态机、支付与结算边界、Agent 协议和 MVP 验收标准；开发计划进一步定义迭代顺序、任务编号、权限边界、安全验收和 MVP 发布门槛。当前推荐路线是“模块化单体控制面 + 卖家节点 Agent + 反向安全隧道 + 整卡租赁”。
